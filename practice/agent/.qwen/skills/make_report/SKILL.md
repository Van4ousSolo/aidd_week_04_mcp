# Навык формирования аналитического отчёта по задачам (Excel)

Навык выполняет детерминированную выгрузку задач из REST API локального сервиса TODO и формирует презентабельную двухстраничную аналитическую книгу Excel (`.xlsx`), состоящую из листов «Реестр задач» и «Сводная аналитика».

## Инструкция по использованию

Запускай скрипт через системный интерпретатор Python из каталога `practice/agent`:

```bash
python .qwen/skills/make_report/generate_report.py --output <ПУТЬ_К_ОТЧЕТУ.xlsx>
```

### Дополнительные параметры CLI:
- `--date YYYY-MM-DD` — контрольная дата анализа (если не указана, используется текущая системная дата).
- `--url http://127.0.0.1:5001` — базовый URL локального TODO API (по умолчанию `http://127.0.0.1:5001`).

### Правила работы:
1. **Безопасность файлов:** скрипт защищен от случайной перезаписи существующих файлов (`FileExistsError`). Если целевой файл уже существует, укажи новое имя (например, `report_v2.xlsx`) или согласуй с пользователем.
2. **Неизменность данных:** скрипт работает в режиме чтения и не модифицирует базу задач в TODO.
3. **Результат:** после успешного завершения скрипт выводит в stdout JSON со сводной статистикой (`total`, `completed`, `in_progress`, `overdue`, `completion_rate`). Предоставь пользователю путь к созданному файлу и ключевые показатели отчёта.
